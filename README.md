# 찍어줄게 — 여자친구 사진 코치

여자친구 사진을 예쁘게 찍기 위한 개인용 앱. 구도·각도·포즈·장소별 팁, 촬영 알림, 용도별 비율 맞춤 보정을 한 화면에서 처리한다.

## 지금 열어보는 방법

```bash
python -m http.server 3000 --directory C:\Users\sj.kim\photo-coach
```

브라우저에서 `http://localhost:3000` 접속. 휴대폰에서 보려면 같은 와이파이에서 `http://(컴퓨터IP):3000`.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 홈 | 인사, 오늘의 해 시간(골든아워), 오늘의 미션 1개, 오늘 5컷 체크, 촬영 기록 |
| 촬영 | 구도 17가지(5:8 법칙·음식샷 포함) / 각도 4축·목표별 추천 / 포즈 25가지+배·팔·턱 점검 / 장소 13곳+배경 공식 / 대사집(부드러운 디렉팅 포함) |
| 카메라 | 실시간 화면에 구도 실루엣 겹쳐 보기, 수평계, 어두움·역광 자동 경고(무료) + ✨AI 코치(PRO): 화면 보고 구도·포즈·위치·빛 제안 |
| 보정 | 사진 넣기 → 용도 비율 크롭 → 무드 12종 → 세부 11개 → 용도별 크기로 저장. 여러 장 넣으면 베스트샷 토너먼트 |
| 알림 | 요일·시간 설정, 골든아워 자동 맞춤, 문구 25종 랜덤 |
| 보관함 | 저장한 구도, 촬영 일지, 증상별 문제 해결 |

## 유료/무료 구분 (사업화 설계)

- 무료 (기기 안 계산 = 원가 0):
  구도 18종·포즈·장소 13곳 추천 레시피·대사·알림·보정(무드 14종)·사진 분석 무드 추천·베스트샷 토너먼트·카메라 오버레이·수평계·밝기/역광 경고·추억 앨범·디데이
- PRO (AI 호출 비용 발생 → 구독 대상, Gemini 사용):
  1. AI 코치 — 카메라 화면을 보고 구도·포즈·위치·빛 제안
  2. 진짜 장소 가이드 — "성수 ○○카페" 실제 장소의 포토스팟·유명 샷·시간대 (검색 결합)
  3. AI 자연 보정 — 잡티·노이즈만 미세 정리, 얼굴·몸·배경 변형 금지 지시, 전후 비교 후 버리기 가능 (2026 트렌드 = 티 안 나는 보정)
  현재는 사용자가 구글 AI 열쇠(무료 발급)를 직접 넣어 개인 사용. 정식 서비스 때는 서버 경유+구독 결제로 전환해야 열쇠 노출이 없다.

## 추억 앨범 (스토리텔링 축)

- 인앱 카메라로 찍으면 날짜·장소 자동으로 앨범 저장. 수동 추가 시 날짜/장소/누구랑(여자친구·친구·가족…)/한 줄 메모.
- 디데이(선택) 등록 시: 홈에 "사귄 지 N일째 + 다음 100일까지 D-n", 각 추억에 "N일째 되던 날" 표기.
- 홈 "그날의 우리": 같은 월-일의 과거 추억 = "1년 전 오늘" 우선 표시.
- 저장은 전부 기기 내부(브라우저 대용량 저장소). 서버 전송 없음.

## 만드는 원칙

- **사진은 절대 서버로 보내지 않는다.** 모든 처리는 브라우저 안에서, 기록은 이 기기의 저장공간에만.
- 회사 개발 표준(사내 Supabase/파일 API)은 **적용하지 않는다** — 개인용·상업화 예정 앱이라 회사 인프라와 분리해야 한다.
- 촬영 지식은 전부 `data.js`에 데이터로 분리. 구도·포즈·무드 추가는 이 파일만 수정.

## 파일

- `index.html` — 껍데기 (탭·시트·토스트)
- `styles.css` — 다크 톤 모바일 UI
- `data.js` — 용도/구도/각도/포즈/장소/무드/알림문구/대사/문제해결 데이터
- `app.js` — 라우팅, 해 시간 계산, 구도 미리보기 SVG, 보정 엔진
- `sw.js`, `manifest.webmanifest`, `icon.svg` — 홈 화면 추가(PWA)

## 보정 엔진

1. `ctx.filter`로 밝기·대비·채도·흑백 (GPU)
2. 픽셀 루프로 색온도·색조·밝은영역·어두운영역·물빠짐·알갱이
3. 3×3 언샤프로 선명하게
4. 방사형 그라디언트로 테두리 어둡게

미리보기는 화면 크기로만 계산(프레임당 약 17ms), 저장은 용도별 원본 해상도(1179×2556 최대 설정에서 약 250ms).

## 배포(나중에)

정적 파일뿐이라 Cloudflare Pages 또는 Vercel에 폴더째 올리면 끝. 개인 사업용이므로 회사 공용 계정이 아닌 **개인/법인 계정**을 새로 만들어 쓴다.

앱스토어에 올리려면 이 웹앱을 껍데기 앱(Capacitor 등)으로 감싸는 방식이 가장 빠르다. 알림을 확실하게 띄우려면 그 단계가 필요하다.
